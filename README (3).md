# DevOps CI/CD Pipeline Using GitHub, Jenkins and Docker

## Introduction

This project demonstrates the basic concepts of DevOps and Continuous
Integration and Continuous Delivery (CI/CD). It uses GitHub for version
control, Jenkins for automation, and Docker for application
containerization.

## Objectives

-   Understand the DevOps workflow.
-   Manage source code using GitHub.
-   Learn the basics of automated build and testing.
-   Package an application using Docker.
-   Understand how CI/CD tools work together.

## Tools

-   Git and GitHub
-   Jenkins
-   Docker
-   Docker Hub
